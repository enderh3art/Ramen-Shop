## Setup

### Prerequisites
- [Node.js](https://nodejs.org/en/download/) (Supports v18, v20, v22, and v24+)

### Commands
Run the following commands:

``` bash
# Install dependencies (only the first time)
npm install

# Run the local server at localhost:8082 (or the next available port)
npm run dev

# Build for production in the dist/ directory
npm run build
```
